# Footy Arena

A simple site for the **FIFA World Cup 2026** — host nations, venues, and the full match schedule across the USA, Canada, and Mexico.

## What's here

- **Home** — tournament overview, host countries, opening-day fixtures, and host cities
- **Fixtures** — every match, grouped by date

Fixture data comes from [openfootball/worldcup.json](https://github.com/openfootball/worldcup.json) (CC0).

## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
pnpm build   # production build
pnpm start   # run production server
```
